# 作業用フォルダ（Git には上げません）

このフォルダの中身は `.gitignore` で除外されています。追跡されているのはこの `README.md` だけで、他に置いたファイルはコミットされず、GitHub にも公開されません。

下書き、指示書、授業の個人メモ、学生に配る前の試作などを自由に置いてください。

## 使い方の例

```
_local/
  README.md        # これだけ追跡される
  指示書.md
  drafts/
    第3回_スライド下書き.pptx
  scratch.ipynb
```

サブフォルダを作っても、その中身はまとめて無視されます。

## 確認方法

意図せず追跡されていないか確かめるには次を実行します。何も表示されなければ除外できています。

```bash
git status --short _local/
git check-ignore -v _local/あなたのファイル名
```

## 注意：クラウドエージェントからは見えません

Cursor のクラウドエージェントは GitHub 側のリポジトリを複製して動くため、ここに置いたファイルは届きません。エージェントに読ませたい指示書は、チャットに本文を貼るか、追跡対象のフォルダ（例: `docs/`）に置いてコミットしてください。

手元の Cursor で動かすエージェントは、このフォルダのファイルも読めます。
