# Python 文法チートシート（シミュレーション工学）

演習で使う Python の文法をまとめたものです。書き方を思い出したいときに参照してください。C 言語を学んだ人向けに、対応する C の書き方も併記しています。

まず2つの約束だけ覚えてください。

1. 行末の `;` も、変数の型宣言も**不要**。
2. ブロックは `{}` ではなく**インデント**（半角スペース4つ）で表す。`if` / `for` / `def` の行末には必ず `:` を付ける。

## 1. 変数と型

値を代入すると型は自動的に決まります（動的型付け）。

```python
a = 7            # int（整数）        C: int a = 7;
x = 2.5          # float（実数）      C: double x = 2.5;
y = 7.           # 7. と書くと float になる
a, r, n = 2, 3, 5    # まとめて代入（a=2, r=3, n=5）

print(a, type(a))    # 値と型を確認 → 7 <class 'int'>
```

`float` は倍精度（64bit、有効桁数 約16桁）で、C の `double` と同じです。単精度で計算したいときは `s = np.float32(0.0)` と書きます（有効桁数 約7桁）。

## 2. 演算子

| 演算子 | 意味 | C との違い |
| --- | --- | --- |
| `+` `-` `*` | 加減乗 | 同じ |
| `/` | **常に実数**の除算。`7 / 3` → `2.333...` | C の `int / int` は整数除算 |
| `//` | 切り捨て除算。`7 // 3` → `2` | C には無い |
| `%` | 剰余。`7 % 3` → `1` | 同じ |
| `**` | べき乗。`2 ** 3` → `8` | C は `pow(2, 3)` |
| `+=` | 累算代入。`total += i` | `i++` は無いので `i += 1` |
| `==` `!=` `<` `>=` | 比較 | 同じ。代入 `=` と混同しないこと |
| `and` `or` `not` | 論理演算 | C の `&&` `\|\|` `!` |

指数表記も使えます。`1.e5` は $1 \times 10^{5}$、`2.12e-12` は $2.12 \times 10^{-12}$ です。

## 3. 画面への表示

`print()` はカンマ区切りで何個でも渡せます（書式指定は不要）。桁数をそろえたいときは文字列の前に `f` を付け、`{変数:書式}` と書きます。

```python
print("a =", a, "x =", x)              # a = 7 x = 2.5
print(f"N={N:>7d}, err={err:.3e}")     # N=     10, err=1.234e-03
```

`:d` は整数、`:.3f` は小数点以下3桁、`:.3e` は指数表記で3桁（`1.234e-03` = $1.234\times10^{-3}$）、`:>7d` は幅7桁で右寄せです。

## 4. 数学関数

ライブラリを **import** してから使います。import はノートブックの先頭に一度書けば十分です。

```python
import math            # 数値1個を扱う数学関数
import numpy as np      # 配列・行列。np という短い名前で使う
```

| 内容 | `math` | `numpy` |
| --- | --- | --- |
| 三角関数 | `math.sin(x)` `math.cos(x)` | `np.sin(x)` `np.cos(x)` |
| 平方根 | `math.sqrt(x)`、`x**0.5` | `np.sqrt(x)` |
| 指数・対数 | `math.exp(x)` `math.log(x)` `math.log10(x)` | `np.exp(x)` `np.log(x)` |
| 円周率 | `math.pi` | `np.pi` |
| 度 → ラジアン | `math.radians(60)` | `np.deg2rad(60)` |

**三角関数の角度はすべてラジアン**です。絶対値は import 不要の `abs(x)` が使えます。

## 5. 条件分岐

```python
if r == 1:                 # C: if (r == 1) {
    s = a * n              #        s = a * n;
elif r > 1:                #    } else if (r > 1) {
    s = a * (r**n - 1) / (r - 1)
else:                      #    } else {
    s = 0.0
```

## 6. 繰り返し（`for` 文）

微小時間ごとに計算を繰り返すので、シミュレーションでは最重要の構文です。Python の `for` は「**用意された並びから要素を順に取り出す**」形をしています。

```python
total = 0
for i in range(1, 6):      # i に 1,2,3,4,5 が順に入る（6 は含まない）
    total += i             # C: for (int i = 1; i < 6; i++) { total += i; }

for N in [10, 100, 1000]:  # リストの要素を直接取り出すこともできる
    print(N)

t = 0.0
while t < 10.0:            # 回数が決まらないときは while
    t += 0.01
```

| 書き方 | 取り出される値 |
| --- | --- |
| `range(5)` | `0, 1, 2, 3, 4`（0 から、5 は含まない） |
| `range(1, 6)` | `1, 2, 3, 4, 5` |
| `range(1, n + 1)` | `1` から `n` まで（`n` 回。この形をよく使う） |
| `range(0, 10, 2)` | `0, 2, 4, 6, 8`（第3引数は増分） |

**終端値は含まれない**のが落とし穴です。1 から `n` まで足すなら `range(1, n + 1)` と書きます。途中で抜けるには `break`、次の回へ飛ばすには `continue` を使います。

## 7. 配列

用途の違う2種類があります。**添字はどちらも 0 から始まります。**

### リスト `[]` — 値を並べて入れておく箱

```python
N_values = [10, 100, 1000, 10000]
errors = [0.0] * 4          # 0.0 を4個。[0.0, 0.0, 0.0, 0.0] と同じ

N_values[0]                 # 1番目の要素 → 10
N_values[-1]                # 最後の要素 → 10000
len(N_values)               # 要素数 → 4
errors[2] = 1.5e-3          # 3番目を書き換える
N_values.append(100000)     # 末尾に追加する
```

### NumPy 配列 `np.array` — 計算・グラフ用の配列

配列全体にまとめて数式を適用できます（ベクトル演算）。

```python
v = np.array([1.0, -1.0])        # リストから作る
z = np.zeros(100)                # 要素 100 個の 0 配列
t = np.linspace(0, 10, 201)      # 0 から 10 を等間隔に 201 点（両端を含む）
y = np.sin(t)                    # 全要素に sin をまとめて適用。for 文は不要
2 * v + 1                        # 各要素に適用される → [3. -1.]
```

`np.array([1, 2]) + 1` は各要素への足し算ですが、リストの `+` は連結（`[1, 2] + [3]` → `[1, 2, 3]`）です。

## 8. 関数

計算式を部品にまとめ、何度も呼び出せるようにします。`def` で定義し、`return` で値を返します。引数と戻り値の型は書きません。

```python
def kinetic_energy(m, v):        # C: double kinetic_energy(double m, double v) {
    return 0.5 * m * v ** 2      #        return 0.5 * m * v * v;  }

e = kinetic_energy(2.0, 3.5)     # 呼び出し。数学の関数と同じ使い方

def geometric_sum(a, r, n):      # for 文と組み合わせた典型的な形
    total = 0.0                  # 合計を入れる変数を先に 0 で用意する
    for k in range(1, n + 1):
        total += a * r ** (k - 1)
    return total                 # インデントの位置に注意（for の外側）

def right_triangle(w, h):                    # 戻り値は2つ以上でもよい
    return 0.5 * w * h, math.sqrt(w**2 + h**2)   # 直角三角形の面積と斜辺の長さ

area, hypotenuse = right_triangle(3.0, 4.0)      # 2つの戻り値をまとめて受け取る
```

関数の中で作った変数（上の `total`）は、その関数の中だけで有効です。

## 9. 行列・ベクトル（NumPy）

```python
A = np.array([[1.0, 2.0], [3.0, 4.0]])   # 2x2 行列。行ごとに [] で囲む
A[0, 1]                                  # 0行1列の要素 → 2.0
A + B        # 要素ごとの和        A * B   # 要素ごとの積（行列積ではない）
A @ x        # 行列 × ベクトル     A @ B   # 行列 × 行列（線形代数の積）
A.T                                      # 転置
np.linalg.inv(A)                         # 逆行列
np.linalg.solve(A, b)                    # 連立一次方程式 Ax = b を解く
eigvals, eigvecs = np.linalg.eig(A)      # 固有値と固有ベクトル（列ごと）
```

`*` は要素ごとの積、`@` が線形代数の積です。混同しやすいので注意してください。

## 11. よくあるエラーと対処

| エラー表示 | 原因と対処 |
| --- | --- |
| `SyntaxError: expected ':'` | `if` / `for` / `def` の行末の `:` 忘れ |
| `IndentationError` | インデントが揃っていない。半角スペース4つで揃え、タブと混ぜない |
| `NameError: name 'x' is not defined` | 変数名の打ち間違い、または定義前に使った。セルを上から順に実行する |
| `TypeError` | 数値と文字列を足したなどの型の不一致。`float(s)` などで変換する |
| `IndexError: index out of range` | 添字が要素数を超えた。添字は `0` から `len(x) - 1` まで |
| `ModuleNotFoundError` | `import numpy as np` などの import 忘れ |
| エラーは出ないが結果が変 | `=` と `==` の混同、`range` の範囲のずれ。途中に `print()` を入れて値を確認する |

Colab ではセルを上から順に実行します。途中のセルだけ実行し直すと変数が古い値のまま残るので、結果が不審なときは上から順に再実行してください。
