# 講義資料

回ごとにディレクトリを作り、その中にスライドや補足ノートを置きます。

```
lectures/
  01_introduction/
    README.md        # その回の概要・到達目標・参考文献
    slides.pdf       # 配布スライド
  02_.../
```

- ディレクトリ名は `回数_英語の短いタイトル`（例: `03_ode_solvers`）とします。
- 編集可能な原稿（`.tex`, `.pptx`, `.md`）と配布用 PDF の両方を置いてかまいません。
- 容量の大きい動画などはリポジトリに入れず、配布先のリンクを `README.md` に書いてください。
