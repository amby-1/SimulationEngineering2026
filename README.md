# シミュレーション工学（2026年度）

振り子の運動（時間発展する非線形微分方程式）を題材に、対象のモデル化・シミュレーション・解析手法を学ぶ授業の資料置き場です。

AI を使えばシミュレーション自体は簡単に実行できます。だからこそ、ブラックボックスのまま使うのではなく、背景にある原理と限界を理解し、結果を的確に評価できることを重視します。

## 受講上の注意

- 授業中に Google Colab 上でプログラムを作成・実行します。**毎回 PC を持参してください。**
- 手計算でモデル化する課題も出します。**ノートと筆記用具も持参してください。**

## 到達目標

1. 常微分方程式を数値的に解くことができる。
2. 数値計算における刻み幅と精度の関係を説明できる。
3. 時間発展シミュレーションの妥当性を評価できる。
4. 状態空間（相平面）においてシミュレーション結果を議論できる。
5. 線形制御をシミュレーション上で実装できる。

キーワード: オイラー法、ルンゲ＝クッタ法、ニュートン法、線形化、固有値、シミュレーション、Python
