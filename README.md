# SimulationEngineering2026

シミュレーション工学（2026年度）の授業資料置き場です。各回は Google Colab のノートブックで進め、参考 PDF をセットで配ります。

## 各回の資料


| 回   | 内容                    | Colab | 参考 PDF |
| --- | --------------------- | ----- | ------ |
| 第1回 | ガイダンス / シミュレーション工学の概観 | 未設定   | 未設定    |


Colab の欄は、クリックすると Google Colab でその回のノートブックが開くリンクです。PDF は `Material/` に置いたファイルへのリンクです。資料ができたら「未設定」を置き換えます。

## ディレクトリ構成


| 場所           | 内容                           |
| ------------ | ---------------------------- |
| `ColabCode/` | 各回の Colab ノートブック（`.ipynb`）   |
| `Material/`  | 各回の参考 PDF                    |
| `Reference/` | シラバス、文献などの参考情報               |
| `_local/`    | 下書きや指示書などの作業用。中身は Git に上げません |


同じ回のノートブックと PDF は、ファイル名の先頭の回数（`01_`、`02_` …）を揃えます。
