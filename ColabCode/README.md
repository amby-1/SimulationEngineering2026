# Colab ノートブック

各回の授業で開くノートブックを置きます。

- ファイル名は `01_短いタイトル.ipynb` のように、回数を先頭に付けます。複数回で使うものは `05-06_短いタイトル.ipynb` とします。
- 同じ回の参考 PDF（`Material/`）と回数を揃えます。
- 学生が開くリンクは、リポジトリ直下の `README.md` に Colab の URL として書きます。GitHub 上のこのファイルへの直接リンクは使いません。
- ノートブックに貼る図は `images/` に置き、`https://raw.githubusercontent.com/.../ColabCode/images/○○.png` の形で参照します。相対パスで書くと Colab で表示されません。
