# 課題

課題ごとにディレクトリを作り、問題文と配布ファイルを置きます。

```
assignments/
  01_first_steps/
    README.md        # 問題文、提出物、締切、評価基準
    template.py      # ひな形（任意）
```

## 提出時の注意

- 提出物の形式（ソースコード / レポート PDF / ノートブック）は各課題の `README.md` に従ってください。
- 実行結果だけでなく、計算手順と考察を必ず記載してください。
- 他人の成果物をそのまま提出することは認めません。参考にした資料は出典を明記してください。
